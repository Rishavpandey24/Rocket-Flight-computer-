# Rocket Flight Computer

A compact and reliable rocket flight computer designed for model and high-power rocketry. This system integrates an ESP32 microcontroller with sensors such as BMP280 (barometric pressure), MPU6050 (IMU), and GPS for real-time flight monitoring.

## Features

* Real-time altitude measurement
* Acceleration and orientation tracking
* Apogee detection
* Data logging to onboard storage
* Telemetry over Wi-Fi/LoRa
* Recovery system deployment support
* Flight data visualization and analysis

## Hardware

* ESP32
* BMP280 Barometric Sensor
* MPU6050 IMU
* GPS Module
* Buzzer and Status LEDs
* Battery Management System

## Applications

* Amateur and educational rocketry
* Flight testing and validation
* Aerospace research projects
* Rocket recovery and tracking

This project aims to provide a low-cost, customizable, and open-source avionics platform for rocket enthusiasts and students.
